# siblings. It is inert with launcherx disabled; leave it.

# System updater: com.google.android.gms (Google OTA, A/B update_engine). No Haier updater; the only
# ota/update package is com.telink.lt.ota (the remote's firmware). Keep both.

# Remote, with the stock home disabled: Netflix, YouTube, Prime Video, Input, voice and the volume ramp
# work with no helper. The gear button does nothing; HOME_KEY_SERVICE was left off to keep the volume ramp.
# Private DNS (dns.adguard-dns.com, hostname mode) stopped all name resolution on this set while the
